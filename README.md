# 🩸 BloodConnect

### Connecting the Right Donor at the Right Time

BloodConnect is a Java-based Blood Donation Management System designed to
connect blood seekers with suitable donors through a centralized platform.

## 📌 Features

- User registration and login
- Donor profile management
- Search donors by blood group, city and age
- Send blood requests
- Accept or reject blood requests
- Donation record management
- Donor cooldown tracking
- Request status tracking
- Admin management

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- JSP
- Java Servlets
- JDBC
- MySQL
- DAO
- Apache Tomcat
- Eclipse

## 🔄 Workflow

Register → Login → Search Donor → Send Request → Accept/Reject → Donation → Cooldown

The objective of BloodConnect is to make the process of finding and connecting
with suitable blood donors more organized, accessible and efficient.
